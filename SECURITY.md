# NearGFix Partner App – Security Policy

## Supported Versions

Security updates are provided for the latest production release of the NearGFix Partner App.

| Version | Supported |
|---|---|
| Latest production release | Yes |
| Current preview release | Testing only |
| Older releases | No |

## Reporting a Vulnerability

We take security vulnerabilities seriously.

If you discover a security issue, please report it privately through GitHub Security Advisories:

https://github.com/GloboGreen-Pvt-Ltd/GGFIX-Partner-App/security/advisories/new

Please include:
- Description of the vulnerability
- Steps to reproduce
- Affected app version
- Potential security impact
- Screenshots or logs, if available

Do not disclose vulnerabilities publicly before they have been investigated.

## Security Measures

The NearGFix platform uses:

- HTTPS for production API communication
- Authentication and role-based authorization
- Secure server-side validation
- Environment-based configuration
- Firebase configuration management
- PostgreSQL database access controls
- Dependency vulnerability scanning
- GitHub security monitoring

## Security Response

Security reports will be reviewed and prioritized according to severity.

Critical vulnerabilities will receive priority attention.

## Sensitive Information

Never commit:
- API secrets or access tokens
- Firebase service-account private keys
- Database passwords
- AWS credentials
- Production signing credentials

## Contact

Report security issues privately using GitHub Security Advisories.
